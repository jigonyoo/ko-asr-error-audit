# ko-asr-error-audit

Korean speech recognition output that reads fluently but is wrong, and the
reference transcripts that are wrong while looking authoritative.

The two worst-scoring utterances in this run were not recognition errors. One
recording stops mid-sentence while its reference transcribes the whole
sentence; the other has a second conversation recorded after the read
sentence. Whisper wrote down what was actually said and was scored 0.713 and
1.235 CER for it. Both were confirmed by listening.

Scope: 100 utterances (50 Zeroth-Korean test, 50 FLEURS `ko_kr` test), Whisper
`small`, CPU int8. Small sample; every number below comes from a committed run
directory and can be recomputed from it.

## Findings

**1. The worst-CER list was dominated by reference/audio mismatches.**

| uid | CER | what the audio contains | verdict |
|---|---|---|---|
| `zeroth-126_003_0376` | 0.713 | 8.54 s file; speech 1.0–7.0 s, digital silence (−79 dBFS) after 7.5 s. Reader stops mid-sentence. | reference longer than the audio |
| `zeroth-105_003_0478` | 1.235 | 20.45 s file; after ~10 s a man and a woman talk off-script. | reference omits real speech |

An error-rate leaderboard reads both as model failures. The length-ratio check
in `koasr/classify.py` (transcript/reference length outside 0.6–1.5) flagged
both; the human listen decided them.

**2. About half of the raw character edits were writing, not hearing.**

Cumulative normalization layers (`koasr/normalize.py`), absolute character edits:

| layer | Zeroth edits | FLEURS edits |
|---|---|---|
| raw | 434 | 235 |
| + NFC | 434 | 235 |
| + drop parenthetical Latin | 434 | 221 |
| + drop punctuation | 377 | 181 |
| + read numerals as Sino-Korean | 325 | 178 |
| + ignore spacing | **208** | **120** |

Zeroth references spell numbers in Hangul (스물 센티미터, 오십 일 퍼센트);
Whisper writes digits. With formatting removed and the two mismatched
recordings excluded, Zeroth CER goes from 0.161 to 0.059.

**3. Meaning changes hide under low CER.** Judged by a person:

| reference | Whisper | CER of the sentence |
|---|---|---|
| 돌연변이**만이** 유전될 수 있고 (*only*) | 돌연변이 **많이** (*many*) | 0.130 |
| **오늘날** 날개를 접을 수 없는 (*nowadays*) | **어느 날** (*one day*) | 0.200 |
| **서기** 400년경에 (*AD*) | **석이** | 0.104 |
| 교전이 발발한 **직후** (*right after*) | **짓고** | 0.118 |
| 매출 일 조 이천 구백 십 구 **억**원 | 1조이 2,919원 (억 dropped) | 0.522 |

## What the tools got wrong

Published on purpose:

- **Parenthetical-Latin layer:** 1 of 1 human-checked applications was wrong.
  `인민 기구(SWAPO)` is read aloud letter by letter; the layer deleted it from
  the reference and turned a correct transcript into an error (row CER 0.111 → 0.233).
  Whether a parenthetical was spoken cannot be decided from text. Other
  applications of the layer are unverified.
- **Classifier "meaning changed" precision: 3 of 10** on a random sample of
  its own "meaning" labels (`runs/precision_sample.json`). Five were
  misspellings that produce non-words (곤층, 말달툼, 거반수), two were
  formatting (던지/든지; 쩜 not mapped to 점). Separating a non-word from a
  real-word substitution needs a lexicon; the classifier has none.
- **Human–machine agreement: 8 of 10** decidable judgments
  (`runs/agreement.json`). The two disagreements are left as they are:
  the dropped 억 (person: ambiguous formatting; machine: number error) and
  아이티 → IT (person: formatting; machine: ambiguous transliteration).
- **Planted defects: near-perfect detection**, zero false alarms on
  format-only controls (`runs/plant_validation.json`). The defects and the
  detector were written by the same author, so this shows the detector does
  what it was designed to do, not that it works on real errors. Finding 2 and
  the precision sample are the real test.
- Not handled: native numerals (스물, 아홉 시) are never generated by the
  numeral layer; `쩜` is not mapped to `점`; English words vs Hangul
  transliteration (nvidia / 엔비디아) are untouched.

## Human judgments

`annotations/judgments.jsonl` holds every judgment with who made it.
Listening judgments (the two mismatched recordings, SWAPO) and the meaning
grades were made by the author. The seven text-only labels in the precision
sample were made by the AI assistant that wrote the classifier and then
reviewed by the author; each record says so.

## Reproduce

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt          # Python 3.14 OK: no `datasets` dependency
python -m pytest -q tests                # 41 tests, offline

python -m koasr.run --dataset zeroth --model small --limit 50     # M1 baseline
python -m koasr.run --dataset fleurs --model small --limit 50
python -m koasr.ablation   runs/<run_dir>                          # M2 normalization
python -m koasr.classify   runs/<run_dir>                          # M3 labels
python -m koasr.plant      runs/<zeroth> runs/<fleurs> --exclude annotations/judgments.jsonl
python -m koasr.agreement  annotations/judgments.jsonl runs/<zeroth> runs/<fleurs>
python -m koasr.clip --dataset zeroth --uid zeroth-126_003_0376   # listen to one row
```

Decoding is pinned (`language="ko"`, `temperature=0`, `beam_size=5`). Each run
directory has a `manifest.json` with model, backend version and data revision.

## Data

Audio is fetched as parquet from the Hugging Face Hub and never committed.

- **Zeroth-Korean**, test split. CC BY 4.0. <https://www.openslr.org/40/>
- **FLEURS** `ko_kr`, test split. CC BY 4.0. <https://huggingface.co/datasets/google/fleurs>
  References use `raw_transcription`, not the pre-normalized `transcription`.
- **Whisper**, OpenAI, MIT license, via faster-whisper.
